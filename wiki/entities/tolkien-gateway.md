# Tolkien Gateway

A community-built fan wiki for Tolkien's Middle-earth — thousands of interlinked pages covering characters, places, events, languages, built over years by volunteers.[^src1]

## Significance

Cited as the **aspirational model** for what a single person can now build with an LLM doing the cross-referencing and maintenance: "you could build something like that personally as you read, with the LLM doing all the cross-referencing and maintenance."[^src1]

Useful as a concrete picture when considering the **book-companion-wiki** use case of the [[llm-wiki-pattern]].
